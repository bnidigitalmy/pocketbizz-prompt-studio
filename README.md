# PocketBizz Prompt Studio

Static single-page tool for generating consistent Google Flow video prompts for the
"Kisah Kak Bizz" animated series (PocketBizz Universe).

Open `index.html` in a browser: each scene has a **Copy Prompt** button that assembles a full
self-contained prompt (character identities + environment + action + camera + lighting + Bizz
Energy Core state + dialogue + style/quality) for consistent AI video generation.

Deployed via Cloudflare Pages (root = `index.html`). Source of truth lives in the private
`pocketbizz-asset-library` repo under `GOOGLE FLOW/`.
